Il metodo

Più di un semplice Web Designer: perché scegliere un profilo ibrido

Molti designer creano layout bellissimi ma difficili da navigare; molti programmatori scrivono ottimo codice trascurando l’impatto visivo. Il mio approccio nasce dall’incontro tra questi due mondi, insieme all’abitudine al contatto diretto con le persone e alla gestione dei clienti che ho maturato sul campo.

2014 – 2025

Esperienza consolidata sul campo

Dal 2014 al 2025 ho lavorato come Web Designer presso l’agenzia Tivitti Web e Comunicazione a Palermo, sviluppando e gestendo decine di siti web per imprese e professionisti locali e nazionali.

WordPress · Elementor

Padronanza di WordPress ed Elementor

Non mi limito a installare template predefiniti. Utilizzo i page builder in modo avanzato, scrivendo codice HTML5, CSS3 e PHP personalizzato per superare ogni limite grafico o funzionale.

2026

Visione Full-Stack e innovazione

Il web evolve velocemente. Per offrire soluzioni sempre all’avanguardia, nel 2026 ho ampliato il mio bagaglio tecnico con un percorso intensivo in Java Full-Stack & AI Engineering, integrando logiche di programmazione avanzata, gestione database (MySQL/PostgreSQL) e framework moderni come Angular.
